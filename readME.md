# Everest Bank

A hypothetical banking website built as a frontend practice project using HTML, CSS, and Bootstrap.

## About

Everest Bank is a fictional banking website I created around the time i got introduced to coding as a frontend practice project to practice Bootstrap and responsive web design.

The project was inspired by the design and presentation of existing banking websites, including Ecobank. I used existing websites as references for some visual ideas, colors, and content while creating my own fictional bank, branding, and page structure.
